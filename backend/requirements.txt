# --- 步骤 08：真实 OCR 提取 ---
# 这三个是**运行依赖**，不是评测工具的依赖：
# - Pillow：图像解码、EXIF 方向校正、去斜与格线检测、格子裁剪。
# - pypdf：区分「带文字层的数字 PDF」与「扫描成图的 PDF」，抽文字层、取内嵌整页图。
#   数字 PDF 那条分流路径**根本不调 OCR**，靠的就是它。
# - pillow-heif：HEIC 解码。iPhone 原图默认是 HEIC，而识别服务的 data URL
#   只吃 jpeg / png，所以进来要先转 JPEG（原始 HEIC 保持不动，它是单据证据）。
#   ⚠️ 缺它时不会崩：上传照样成功、原件照样保存，只是那一份提取会明确报
#   「本机没有 HEIC 解码器」并告诉人怎么办。
